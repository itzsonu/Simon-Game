# Simon Says Game

A simple Simon Says memory game built using **HTML**, **CSS**, and **JavaScript**. The game generates a sequence of colors, and the player must repeat the same sequence in the correct order. Each level adds one new color to the pattern, making the game harder as you progress. [web:20][web:21][web:29]

## Features

- Start the game by pressing any key. [web:20][web:21]
- Random color sequence generation.
- User click detection and answer checking.
- Level-based progression.
- Game over message with score display.
- Simple flash effects for game and user actions.

## Technologies Used

- HTML
- CSS
- JavaScript [web:24][web:29]

## How to Play

1. Press any key to start the game. [web:20][web:21]
2. Watch the color that flashes.
3. Click the same color button.
4. In the next level, repeat the full sequence in order.
5. If you click the wrong color, the game ends and your score is shown. [web:20][web:21]

## JavaScript Logic

- `gameSeq` stores the sequence generated by the game.
- `userSeq` stores the sequence entered by the player.
- `levelUp()` increases the level and adds a new random color.
- `gameFlash()` flashes the button selected by the game.
- `userFlash()` flashes the button clicked by the user.
- `checkAns()` compares the user's sequence with the game sequence.
- `reset()` resets the game after a wrong answer.
